# Contributing

Thanks for helping improve this repository! Please follow this simple guide so your changes are easy to review.

## How to contribute

- **Open a GitHub issue** first — use the issue tracker to describe a bug, a feature, or an improvement before writing code.
- **Create a feature branch** from `main` (e.g. `add-contributing-guide`) so your work stays isolated until it is ready to merge.
- **Make small, focused changes** in single-purpose commits and keep pull requests narrow.
- **Write a clear pull request** that links the related issue and explains what changed and why.
- **Request a review** from a maintainer once the branch is ready.
- **Respond to feedback** with updated commits or follow-up questions, then keeppolish until approved.
- **Close issues out** with a summary comment and mark the issue closed when the change is merged.
